# 校园二手交易平台设计与实现（Angular + FastAPI + MySQL）

## 一、项目概述

### 项目背景

面向在校学生，实现校内闲置物品发布、浏览、搜索、聊天议价、订单交易、个人中心、分类管理的二手交易平台。前后端分离架构：

- **前端**：Angular 20+，负责页面渲染、表单、交互、路由、状态管理
- **后端**：FastAPI，提供 RESTful 接口，自动生成接口文档，异步 IO
- **数据库**：MySQL 8.0，存储用户、商品、订单、留言、分类等业务数据
- **辅助**：JWT 身份认证、文件上传（商品图片）、密码加密、分页、模糊搜索

### 核心目标

1. 学生注册登录，发布闲置商品。
2. 商品浏览、分类筛选、关键词搜索。
3. 商品收藏、私信沟通。
4. 下单交易、订单状态管理。
5. 个人中心：我的发布、我的购买、我的收藏、个人信息修改。
6. 后台管理员：商品审核、用户管理、分类管理、订单查看。

### 技术栈清单

表格

| 分层     | 技术                                                         |

> 说明：毕业设计不做真实支付，订单仅模拟状态流转。

## 二、系统需求分析

### 功能性需求

#### 用户端（学生）

1. 用户注册、登录、退出、修改个人资料、修改密码
2. 商品：发布二手商品（多图、标题、描述、价格、分类、新旧程度）、编辑、下架删除
3. 商品列表：分页、按分类筛选、关键词搜索、按价格排序
4. 商品详情：查看信息、收藏、联系卖家
5. 收藏管理：收藏 / 取消收藏，查看我的收藏
6. 消息：买卖双方私信聊天
7. 订单：创建订单、查看订单、确认交易完成
8. 个人中心：我的发布、我买到的、我卖出的

#### 管理员端

1. 管理员登录
2. 用户管理：查看学生用户、禁用账号
3. 商品管理：审核商品、下架违规商品
4. 分类管理：新增、编辑、删除商品分类
5. 订单查看：全部订单记录

### 非功能性需求

1. 安全性：密码 bcrypt 加密存储，JWT 令牌鉴权，接口权限控制
2. 易用性：页面响应友好，表单校验
3. 性能：列表分页查询，避免一次性返回大量数据
4. 可维护：前后端分离，接口文档自动生成，分层代码结构

### 核心模块说明

1. **db.py**：创建 SQLAlchemy engine、session 会话工厂
2. **dependencies.py**：`get_current_user()` 依赖，解析 JWT，接口鉴权
3. **schemas**：入参校验、返回数据序列化
4. **api 路由**：拆分模块，`include_router`聚合到 main.py
5. **utils**：密码哈希；文件上传保存到本地 uploads 目录，返回访问 url

- GET `/api/goods` 商品列表（分页、搜索、分类筛选）
- POST `/api/goods` 发布商品（带图片上传）
- GET `/api/goods/{id}` 商品详情
- POST `/api/favorite` 收藏商品
- POST `/api/order` 创建订单
- GET `/api/order/my` 查询我的订单
- POST `/api/chat/message` 发送消息

## 六、业务流程

### 1. 用户发布商品流程

用户登录 → 进入发布页面 → 填写标题、价格、描述、选择分类、上传图片 → 提交请求到后端 → 后端保存 goods+goods_image 记录，状态为待审核 → 管理员审核通过变为上架 → 首页可见。

### 2. 购买下单流程

浏览商品详情 → 点击下单 → 创建订单记录（买家、卖家、商品、价格）→ 生成订单号 → 双方在订单页面查看状态 → 线下完成交易后，确认完成，更新订单状态。

### 3. 聊天流程

商品详情点击联系卖家 → 进入聊天窗口 → 发送消息保存 chat_message 表 → 加载双方历史聊天记录。

 四、实现要点

 - AuthService：signal<User|null> 当前用户；token/user 持久化 localStorage；isAdmin() 辅助
 - authInterceptor：请求克隆加 Authorization；捕获 401 → authService.logout() + router.navigate(['/login'])
 - 图片：apiUrl + path 拼接（tools: 封装 imageUrl() 纯函数或 pipe）；封面缺失显示占位图
 - 发布/编辑商品：FormData + images 多文件；编辑模式复用表单（后端 PUT /api/goods/{id} 提交 JSON，图片不可改，仅改字段）
 - 聊天：打开会话即拉 history（自动标已读），setInterval 10s 轮询当前会话新消息与会话列表；布局中未读数也轮询
 - 管理员审核：PUT /api/goods/admin/{id}/audit?approved=true|false
 - 分页统一用 Material Paginator，page_size=12（网格 3~4 列）
 - 中文 UI，价格 ¥xx.xx

 1. npm run build（frontend 目录）无编译错误
 2. 启动后端（backend/.venv，参考记忆：venv 激活后 python main.py，MySQL 在 192.168.21.146:3307）
 3. ng serve 启动前端，浏览器走通主流程：
   - admin/admin123 登录 → 后台审核测试商品
